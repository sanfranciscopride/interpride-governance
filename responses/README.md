# InterPride Governance Advisory Memoranda & Official Responses

This repository contains official advisory memoranda, formal interpretations, and governance responses issued by the Governance Committee Co-Chairs.

## Numbering Convention
Each document follows the standardized format:
`RESP-YYYY-NNN-<Topic-Slug>.md`

- `YYYY`: Calendar year of issuance (e.g., `2026`).
- `NNN`: Three-digit sequential response number (e.g., `001`, `002`).
- `<Topic-Slug>`: Brief kebab-case description of the matter addressed.

---

## Standard Structure for Official Responses

Every response must adhere to the following template:

1. **Header Metadata**:
   - Memorandum Number
   - Date of Issuance
   - To / From / Copies
   - Subject
   - Status (e.g., *Official Advisory*, *Interim Guidance*, *Binding Determination*)

2. **Executive Overview / Narrative Summary**:
   - Concise plain-language summary of the inquiry, the operational context, and the bottom-line determination.

3. **Governing Authority & Exact Citations**:
   - Precise citations to the Bylaws, Standing Rules (SR), Member Resolutions, Conference Policies, or parliamentary authorities, quoting controlling text verbatim.

4. **Legal & Procedural Analysis**:
   - Detailed justification, analysis of conflicts, precedent, and operational context.

5. **Directives & Recommended Action Plan**:
   - Immediate operational instructions for meeting facilitators, conference chairs, board officers, or delegates.
